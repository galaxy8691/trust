## 🔴 致命（1 项）

### S01：整数字面量全链路 `i32` 无法承载 2^53

**现状：** `IntLiteral(i32)` 从 lexer → AST → HIR → TIR 全链路一致。`9007199254740993` 远超 `i32::MAX`（约 2.1×10^9），当前 lexer `s.parse().unwrap_or(0)` 会溢出。

| 位置 | 当前类型 |
|------|---------|
| `lexer.rs:113` | `IntLiteral(i32)` |
| `ast.rs:236` | `Expr::IntLiteral(i32)` |
| `hir.rs:192` | `HirExpr::IntLiteral(i32, Span)` |
| `tir.rs:116` | `TirValue::IntLiteral(i32)` |

**规格书遗漏：** Step 1b 只说"推断改为 `HirType::Number`"，未要求将字面量**载荷类型**从 `i32` 升级。MS-2.2-5 的 `let big = 9007199254740993` 验收用例在 `i32` 全链路下无法通过。

**修正：** 新增 Step 1d，将全链路 `IntLiteral(i32)` → `IntLiteral(f64)`。同时更新 lexer 解析逻辑（直接 parse 为 f64）。

## 🟠 不一致（1 项）

### S02：精度警告级别冲突

| 来源 | 表述 |
|------|------|
| 设计 §2.2 | "发出 **help 级别警告**" |
| TODO §2.2.4 | "`Warning` 级别诊断（`Severity::Warning`），可附 `Help` 子诊断" |
| spec TYP-REQ-001 | "`Warning` 级别诊断，附 `Help` 子诊断" |
| 2.2-spec MS-2.2-5 | "`Warning` 级别诊断（`Severity::Warning`），附 `Help` 子诊断" |

`Severity::Help` 是子诊断级别，不能独立作为顶层警告发出。**建议统一为 `Warning` + `Help` child**，并附 PR 同步修正设计文档 §2.2 的措辞。
