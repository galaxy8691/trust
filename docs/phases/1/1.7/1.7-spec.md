## 0. 文件说明

本规格书定义 **Phase 1.7**（`trustc` crate：编译器入口 + CLI + 编译管线编排 + 端到端验证）的工程范围、成功标准、验收条件。

**背景：** `trustc` 是编译管线的**最终站**——依赖全部编译器 crate（parser / HIR / TIR / codegen / error），负责：

1. **CLI 入口**：子命令 `compile` / `check` / `eval`，flags `--error-format=json` / `--fix` / `--verbose` / `--quiet` / `-o`。
2. **编译管线编排**：Parse → HIR → TIR → Codegen → rustc 五阶段串行，按 constraints §11.5 错误恢复策略处理。
3. **统一错误汇总**：各阶段 `Vec<Diagnostic>` 收集 → `format_diagnostics()` JSON/Text 输出到 stderr。
4. **`--fix` 交互确认**：调用 `suggest_fixes()` 生成建议，逐条 `y/N` 确认后输出修复文本（不修改源文件）。
5. **端到端验证**：承接 1.5→1.6→1.7 逐级下沉的 6 条集成验证项。

**一句话成功：** `trustc compile hello.trust` 编译输出 `Hello, Trust!`；`--error-format=json` 输出符合 NDJSON；全部子命令正常执行。

## 1. 成功标准

> **MS 层次说明（K29 fix）：** MS-1.7-1/2/3/5 描述**管线运行时行为**（编译器如何执行）；MS-1.7-4 描述**项目交付标准**（里程碑验收条件）。二者处于不同语义层次——管线行为约束如何编译，交付标准约束是否可验收。当 TIR 限制导致控制流场景无法通过时，编译器正确拒绝（满足 MS-1.7-1），但项目不因此阻塞交付（满足 MS-1.7-4）。

**MS-1.7-1（编译管线可执行）：** `trustc compile <file>` 完成 Parse→HIR→TIR→Codegen→rustc 全流程，生成可执行二进制。Parse 阶段有 Error 级别诊断时终止后续阶段。HIR/TIR 阶段有 Error 时**收集并继续检查**（constraints §3.1.1 错误收集策略），所有错误汇总输出到 stderr 后终止。TIR 零错误是 codegen 的前置条件。

**MS-1.7-2（子命令正确）：** `check` 仅类型/所有权检查（Parse→HIR→TIR，跳过 codegen+rustc）。`eval "<expr>"` 将表达式包装为 `function main() { console.log(<expr>); }` 后走 compile 管线并执行。`--fix` 交互式确认修复建议（逐条 y/N），Phase 1 不修改源文件。

**MS-1.7-3（错误输出格式）：** `--error-format=json` 输出 `format_diagnostics(&diags, false)` 到 stderr。默认格式为纯文本逐条打印到 stderr。`--quiet` 时仅输出 JSON/Text，不显示进度。

**MS-1.7-4（端到端验证）：** 承接 1.6 下沉的 6 条集成验证项通过 trustc 管线验证。若 TIR 所有权检查继续拦截控制流场景（F2-F5），标注为"TIR 限制 → 1.8"，不阻塞 trustc 自身交付。

**MS-1.7-5（P0 约束遵守）：** 零 `unwrap()`/`expect()`（使用 `?` 传播和 `match`）。所有函数上方标注 `// §X.Y.Z:` 章引。零 `unsafe`。`cargo test -p trustc` 全绿。`cargo fmt --check` 和 `cargo clippy -D warnings` 通过（trust_tir 预存 warning 除外——已在 §7 标注）。

#### 3.1.2 参数解析实现

```rust
// Trust 设计文档 §9.1: 手写参数解析（零外部依赖，Phase 1 不使用 clap）
fn parse_args(args: &[String]) -> Result<CliOptions, String> {
    let mut command = None;
    let mut error_format = OutputFormat::Text;
    let mut fix_mode = false;
    let mut verbose = false;
    let mut quiet = false;
    let mut output_path = String::from("./output");

    let mut i = 1; // 跳过程序名
    while i < args.len() {
        match args[i].as_str() {
            "compile" => {
                i += 1;
                if i >= args.len() { return Err("compile requires <file>".into()); }
                command = Some(Command::Compile { file: args[i].clone() });
            }
            "check" => {
                i += 1;
                if i >= args.len() { return Err("check requires <file>".into()); }
                command = Some(Command::Check { file: args[i].clone() });
            }
            "eval" => {
                i += 1;
                if i >= args.len() { return Err("eval requires <expr>".into()); }
                command = Some(Command::Eval { expr: args[i].clone() });
            }
            "--error-format" => {
                // 支持 `--error-format=json` 和 `--error-format json` 两种形式
                i += 1;
                if i < args.len() && args[i] == "json" {
                    error_format = OutputFormat::Json;
                } else {
                    return Err("--error-format requires `json`".into());
                }
            }
            s if s.starts_with("--error-format=") => {
                if s == "--error-format=json" {
                    error_format = OutputFormat::Json;
                } else {
                    return Err(format!("unknown error format: {}", &s[15..]));
                }
            }
            "--fix" => fix_mode = true,
            "--verbose" | "-v" => verbose = true,
            "--quiet" | "-q" => quiet = true,
            "--output" | "-o" => {
                i += 1;
                if i >= args.len() { return Err("-o requires <path>".into()); }
                output_path = args[i].clone();
            }
            other => return Err(format!("unknown flag: {}", other)),
        }
        i += 1;
    }

    let command = command.ok_or("no command specified (compile/check/eval)")?;
    Ok(CliOptions { command, error_format, fix_mode, verbose, quiet, output_path })
}
```

#### 3.2.1 CompileSession

```rust
// §11.5: 编译会话——收集各阶段 Diagnostic
struct CompileSession {
    diagnostics: Vec<Diagnostic>,
    error_count: usize,
    warning_count: usize,  // K8 fix: 统计 Warning 级别诊断
    format: OutputFormat,
    verbose: bool,
    quiet: bool,
}

impl CompileSession {
    fn new(format: OutputFormat, verbose: bool, quiet: bool) -> Self { ... }

    // §11.5: 添加诊断（自动归类 Error/Warning）
    fn add(&mut self, diag: Diagnostic) {
        match diag.level {
            Severity::Error => self.error_count += 1,
            Severity::Warning => self.warning_count += 1,
            _ => {}
        }
        self.diagnostics.push(diag);
    }

    fn has_errors(&self) -> bool { self.error_count > 0 }

    // Trust 设计文档 §9.1.1: 输出所有诊断到 stderr
    fn emit(&self) {
        if self.diagnostics.is_empty() { return; }
        match self.format {
            OutputFormat::Json => {
                eprintln!("{}", format_diagnostics(&self.diagnostics, false));
            }
            OutputFormat::Text => {
                for diag in &self.diagnostics {
                    eprintln!("{}: {}", diag.code, diag.message);
                }
            }
        }
    }

    // §11.5: 显示阶段进度（--verbose）
    fn log_stage(&self, name: &str) {
        if self.verbose && !self.quiet {
            eprintln!("[trustc] {} ...", name);
        }
    }
}
```

#### 3.2.2 管线主函数

```rust
// §11.5: 编译管线编排入口
fn run(opts: CliOptions) -> Result<(), String> {
    let mut session = CompileSession::new(opts.error_format, opts.verbose, opts.quiet);

    let result = match opts.command {
        Command::Compile { file } => {
            let rust_code = run_pipeline(&file, &mut session, true)?;
            if !session.has_errors() {
                compile_with_rustc(&rust_code, &opts.output_path, &mut session)?;
            }
            Ok(())
        }
        Command::Check { file } => {
            run_pipeline(&file, &mut session, false)?;
            Ok(())
        }
        Command::Eval { expr } => {
            let wrapped = wrap_eval_expr(&expr);
            // 内联临时文件写入（K11 fix: 不依赖 write_temp_file 抽象）
            let tmp_file = format!("{}/__trust_eval.trust", opts.output_path);
            std::fs::create_dir_all(&opts.output_path)
                .map_err(|e| format!("mkdir {}: {}", opts.output_path, e))?;
            std::fs::write(&tmp_file, &wrapped)
                .map_err(|e| format!("write {}: {}", tmp_file, e))?;
            let rust_code = run_pipeline(&tmp_file, &mut session, true)?;
            if !session.has_errors() {
                let eval_output = format!("{}/__trust_eval_out", opts.output_path);
                compile_with_rustc(&rust_code, &eval_output, &mut session)?;
                run_binary(&eval_output)?;
            }
            Ok(())
        }
    };

    // --fix 模式在所有子命令执行后、emit 之前调用
    if opts.fix_mode && session.has_errors() {
        run_fix_mode(&session.diagnostics);
    }

    session.emit();
    if session.has_errors() {
        Err(format!("{} error(s) found", session.error_count))
    } else {
        result
    }
}
```

#### 3.2.3 管线阶段

```rust
// §11.5: 五阶段编译管线（K1 fix: 四阶段→五阶段）
fn run_pipeline(file: &str, session: &mut CompileSession, codegen: bool) -> Result<String, String> {
    let src = std::fs::read_to_string(file).map_err(|e| format!("read {}: {}", file, e))?;

    // 1. Parse
    session.log_stage("parse");
    let mut p = trust_parser::parser::Parser::new(&src, file);
    let prog = p.parse_program();
    for diag in &p.diagnostics {
        session.add(convert_parser_diag(diag));
    }
    if session.has_errors() {
        return Err("parse errors".into());
    }

    // 2. HIR（K2 fix: 错误收集后继续 TIR，不提前返回——constraints §3.1.1）
    session.log_stage("hir");
    let mut hir_diags = vec![];
    let mg = trust_parser::module_graph::ModuleGraph::new();
    let mut hir = trust_hir::name_res::resolve_names(&prog, &mg, &mut hir_diags);
    trust_hir::typeck::check_types(&mut hir, &mut hir_diags);
    for d in &hir_diags {
        session.add(convert_hir_diag(d));
    }

    // 3. TIR
    session.log_stage("tir");
    let tir = match trust_tir::tir::lower_hir(&hir) {
        Ok(t) => t,
        Err(diags) => {
            for d in &diags { session.add(convert_tir_diag(d)); }
            return Err("TIR lowering errors".into());
        }
    };
    // 移动/借用错误收集（K28 fix: 使用 if let Err 而非 unwrap_or_default）
    if let Err(move_errors) = trust_tir::moveck::check_moves(&tir) {
        for e in &move_errors { session.add(convert_move_error(e)); }
    }
    if let Err(borrow_errors) = trust_tir::borrowck::check_borrows(&tir) {
        for e in &borrow_errors { session.add(convert_borrow_error(e)); }
    }

    // 4. Codegen（仅在 TIR 零错误时运行）
    if codegen && !session.has_errors() {
        session.log_stage("codegen");
        match trust_codegen::codegen::generate_rust(&tir) {
            Ok((rust_code, _source_map)) => Ok(rust_code),
            Err(errors) => {
                for e in &errors { session.add(convert_codegen_error(e)); }
                Err("codegen errors".into())
            }
        }
    } else {
        Ok(String::new())
    }
}
```

```rust
// Trust 设计文档 §9.4: 将表达式包装为完整 Trust 程序
fn wrap_eval_expr(expr: &str) -> String {
    let escaped = expr
        .replace('\\', "\\\\")  // 先转义反斜杠（防止后续步骤引入的 \ 被二次转义）
        .replace('"', "\\\"")
        .replace('{', "\\{")
        .replace('}', "\\}")
        .replace('\n', " ");
    format!(
        "function main(): void {{\n    console.log({escaped});\n}}\n",
        escaped = escaped
    )
}
```

#### 3.2.5 rustc 编译

```rust
// design-constraints §11.x: 调用 rustc 编译生成的 Rust 源码（K13 fix: 章引修正）
fn compile_with_rustc(rust_code: &str, output: &str, session: &mut CompileSession) -> Result<(), String> {
    use std::process::Command;

    let temp_rs = format!("{}.rs", output);
    std::fs::write(&temp_rs, rust_code).map_err(|e| format!("write {}: {}", temp_rs, e))?;

    // 读取 FERRO_RT_LIB 环境变量或使用默认路径
    let ferro_rt_dir = std::env::var("FERRO_RT_LIB")
        .unwrap_or_else(|_| "target/debug".to_string());

    let status = Command::new("rustc")
        .args([
            "--edition", "2021",
            "-L", &ferro_rt_dir,
            "--extern", &format!("ferro_rt={}/libferro_rt.rlib", ferro_rt_dir),
            "-o", output,
            &temp_rs,
        ])
        .status()
        .map_err(|e| format!("rustc: {}", e))?;

    if !status.success() {
        return Err("rustc compilation failed".into());
    }
    Ok(())
}

fn run_binary(path: &str) -> Result<(), String> {
    use std::process::Command;
    let output = Command::new(path)
        .output()
        .map_err(|e| format!("run {}: {}", path, e))?;
    print!("{}", String::from_utf8_lossy(&output.stdout));
    Ok(())
}
```

#### 3.2.6 `--fix` 交互模式

```rust
// Trust 设计文档 §8.x: 交互式修复确认（K13 fix: 章引修正；Phase 1 不修改源文件，仅输出建议）
fn run_fix_mode(diagnostics: &[Diagnostic]) {
    for diag in diagnostics {
        let fixes = trust_error::fix_suggest::suggest_fixes(diag);
        for fix in &fixes {
            eprintln!("{}: {}", diag.code, diag.message);
            eprintln!("help: {}", fix.message);
            eprintln!("  → {}", fix.replacement);
            eprintln!("应用此修复？(y/N): ");

            let mut input = String::new();
            std::io::stdin().read_line(&mut input).ok();
            if input.trim().to_lowercase() == "y" {
                eprintln!("[trustc] 修复建议已记录（Phase 1 不自动修改源文件）");
                eprintln!("  建议内容：{}", fix.replacement);
            }
        }
    }
}
```

### 3.3 跨 crate 错误类型转换（~60 行）

> **K6 fix:** Trust.toml 最小解析已从 §2.1 纳入项移入 §2.2 排除项。Phase 1 编译器以文件路径直接输入。
> **K7 fix:** TIR/Move/Borrow 错误转换使用具体类型（`DiagError`/`MoveError`/`BorrowError`），保留源码 span 信息。

```rust
// §11.5: 各阶段错误类型 → trust_error::Diagnostic 转换

/// Span 转换辅助
fn span_to_source_span(span: &trust_parser::ast::Span) -> SourceSpan {
    SourceSpan {
        file: span.file.clone(),
        line_start: span.line_start,
        col_start: span.col_start,
        line_end: span.line_end,
        col_end: span.col_end,
        label: None,
    }
}

/// 转换 parser::Diagnostic → trust_error::Diagnostic（K9 fix: Warning 正确映射）
fn convert_parser_diag(diag: &trust_parser::parser::Diagnostic) -> Diagnostic {
    let span = span_to_source_span(&diag.span);
    match diag.level {
        parser::DiagLevel::Error =>
            Diagnostic::error(ErrorCode::E0001, format!("parse: {}", diag.message), span),
        parser::DiagLevel::Warning =>
            Diagnostic::warning(ErrorCode::E0001, format!("parse: {}", diag.message), span),
    }
}

/// 转换 HIR DiagError → trust_error::Diagnostic
fn convert_hir_diag(diag: &trust_hir::name_res::DiagError) -> Diagnostic {
    let span = span_to_source_span(&diag.span);
    Diagnostic::error(ErrorCode::E0425, format!("hir: {}", diag.message), span)
}

/// 转换 TIR DiagError → trust_error::Diagnostic（K7 fix: 使用具体类型 + 源码 span）
fn convert_tir_diag(diag: &trust_hir::name_res::DiagError) -> Diagnostic {
    let span = span_to_source_span(&diag.span);
    Diagnostic::error(ErrorCode::E9999, format!("tir: {}", diag.message), span)
}

/// 转换 MoveError → trust_error::Diagnostic（K7 fix: 具体类型 + 双 span）
fn convert_move_error(e: &MoveError) -> Diagnostic {
    Diagnostic::error_with_secondary(
        ErrorCode::E0382,
        format!("move: {}", e.message),
        span_to_source_span(&e.moved_at),
        vec![span_to_source_span(&e.used_at)],
    )
}

/// 转换 BorrowError → trust_error::Diagnostic（K7 fix: 具体类型 + 双 span）
fn convert_borrow_error(e: &BorrowError) -> Diagnostic {
    Diagnostic::error_with_secondary(
        ErrorCode::E0501,
        format!("borrow: {}", e.message),
        span_to_source_span(&e.first_borrow_at),
        vec![span_to_source_span(&e.conflict_at)],
    )
}

/// 转换 CodegenError → trust_error::Diagnostic
fn convert_codegen_error(e: &CodegenError) -> Diagnostic {
    Diagnostic::error(
        ErrorCode::E9999,
        format!("codegen: {}", e.message),
        span_to_source_span(&e.span),
    )
}
```

## 6. 风险登记册

| 风险 | 可能性 | 影响 | 缓解措施 |
|------|--------|------|---------|
| 各阶段 Span 类型不一致导致 Diagnostic 定位错误 | 低 | JSON 输出行列号不准确 | 端到端测试验证错误信息含文件名；新增 `span_to_source_span` 辅助统一转换 |
| Codegen 生成代码无法被 rustc 编译 | 中 | `compile` 在最后一步失败 | `check` 先验证 HIR/TIR；codegen 有 rustc 编译测试 |
| for/while/loop 端到端被 TIR 所有权检查拦截 | 中 | 下沉项仍无法完成 | 测试用 `INFO skip` 逻辑，标注 TIR 限制 → 1.8 |
| `eval` 表达式覆盖不完整 | 低 | 复杂表达式求值失败 | Phase 1 仅简单表达式，范围已在 §2.2 明确 |
| 手写参数解析不带 clap 过于简陋 | 低 | 用户体验差 | Phase 2 评估引入 clap |
| rustc 编译依赖本地 target/debug 路径 | 中 | CI 环境路径可能不同 | 通过环境变量 `FERRO_RT_LIB` 注入路径 |
