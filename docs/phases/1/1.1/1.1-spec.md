### 3.3 CI/CD 配置

#### 3.3.1 `.github/workflows/ci.yml` 完整规格

**触发条件：** PR 到 `main` 或 `phase1-compiler`；push 到 `main`。

```yaml
name: CI

on:
  pull_request:
    branches: [main, phase1-compiler]
  push:
    branches: [main]

env:
  CARGO_TERM_COLOR: always
  RUSTFLAGS: "-D warnings"

jobs:
  # ========== JOB 1: 基础检查（stable） ==========
  test-stable:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
      - run: cargo test --workspace
      - run: cargo build --workspace --release  # 确认 release 构建不失败

  # ========== JOB 2: Clippy + Fmt（stable） ==========
  lint:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
        with:
          components: clippy, rustfmt
      - run: cargo fmt --check --all
      - run: cargo clippy --workspace -- -D warnings

  # ========== JOB 3: Unsafe 检查（P0） ==========
  no-unsafe:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      # P0: trust_parser, trust_hir, trust_tir 中禁止 any unsafe
      - run: |
          for crate in trust_parser trust_hir trust_tir; do
            if grep -r "unsafe" "crates/$crate/src/" 2>/dev/null; then
              echo "ERROR: unsafe found in $crate (prohibited by constraints §3.2 P0)"
              exit 1
            fi
          done
          echo "OK: no unsafe in parser/hir/tir"

  # ========== JOB 4: 覆盖率（nightly，P1） ==========
  coverage:
    runs-on: ubuntu-latest
    continue-on-error: true  # nightly 可能不稳定，不阻塞 merge
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@nightly
      - name: Install tarpaulin
        run: cargo install cargo-tarpaulin
      - name: trust_tir (≥85%)
        run: cargo tarpaulin -p trust_tir --fail-under 85 --out xml
      - name: trust_parser (≥70%)
        run: cargo tarpaulin -p trust_parser --fail-under 70 --out xml
      - name: trust_hir (≥70%)
        run: cargo tarpaulin -p trust_hir --fail-under 70 --out xml
      - name: trust_codegen (≥70%)
        run: cargo tarpaulin -p trust_codegen --fail-under 70 --out xml

  # ========== JOB 5: Miri unsafe 验证（nightly，P1） ==========
  miri:
    runs-on: ubuntu-latest
    continue-on-error: true
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@nightly
        with:
          components: miri
      - run: cargo miri test -p ferro_rt

  # ========== JOB 6: MSRV 测试（P1） ==========
  msrv:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@1.63
      - run: cargo test --workspace
```

**验收标准：**
- AC-INFRA-004: 所有 job 在 PR 时自动触发
- AC-INFRA-005: `test-stable`、`lint`、`no-unsafe` 必须通过才可 merge（不可 `continue-on-error`）
- AC-INFRA-006: `coverage`、`miri` 允许 `continue-on-error`（nightly 不稳定），失败时显示 warning
