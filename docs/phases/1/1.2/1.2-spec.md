### 3.1 AST 节点定义（`ast.rs`）

#### 3.1.1 Source Span

每个 AST 节点必须携带 source span：

```rust
#[derive(Debug, Clone, PartialEq)]
pub struct Span {
    pub file: String,          // 源文件路径
    pub line_start: u32,       // 1-based
    pub line_end: u32,
    pub col_start: u32,        // 1-based
    pub col_end: u32,
}
```

#### 3.1.2 表达式节点

```rust
#[derive(Debug, Clone, PartialEq)]
pub enum Stmt {
    Let(LetStmt),
    Const(ConstStmt),
    Shared(SharedStmt),
    Function(FunctionDecl),
    If(IfExpr),
    For(ForStmt),
    ForOf(ForOfStmt),
    While(WhileStmt),
    Loop(LoopExpr),
    Return(ReturnStmt),
    Break(BreakStmt),
    Continue(ContinueStmt),
    Switch(SwitchStmt),        // Phase 2
    Match(MatchExpr),          // Phase 2
    IfLet(IfLetStmt),          // Phase 2
    Select(SelectStmt),        // Phase 4
    Expr(Expr),
}

pub struct Program {
    pub imports: Vec<ImportDecl>,
    pub statements: Vec<Stmt>,
    pub span: Span,
}
```

**Phase 1 实际解析的变体：** `Let`、`Const`、`Shared`、`Function`、`If`、`For`、`ForOf`、`While`、`Loop`、`Return`、`Break`、`Continue`、`Expr`。其余变体（`Switch`/`Match`/`IfLet`/`Select`）占位——parser 遇到对应语法时报错"暂不支持"，但 HIR/TIR 可安全遍历所有变体。


### 3.2 Lexer（词法分析器）（`lexer.rs`）

#### 3.2.1 Token 定义

```rust
#[derive(Debug, Clone, PartialEq)]
pub enum TokenKind {
    // 关键字（40 个，按 spec §LEX-REQ-001）
    Let, Mut, Const, Shared,
    Function, Fn,               // fn 仅在 extern 块内合法
    InOut, Move,
    Spawn, Async, Await, Select,
    If, Else, For, Of, While, Loop, Break, Continue, Return, Throw,
    Switch, Case, Default, Match,
    Import, Export, From, As,
    Interface, Type, Impl, Extends, This, Dyn,
    Test,
    Extern,
    // 字面量
    True, False, Undefined, None_,
    Some_, Ok_, Err_,
    Rc, Arc, Weak, Box_,
    // 类型名
    Number, String, Boolean, BigInt, Void,
    // 字面量值
    IntLiteral(i32),
    FloatLiteral(f64),
    BigIntLiteral(i64),
    StrLiteral(String),
    TemplateLiteral(Vec<TemplatePart>),  // 含插值表达式
    // 运算符 / 分隔符
    Plus, Minus, Star, Slash, Percent,
    Eq, EqEq, Ne, Lt, Gt, Le, Ge,
    And, Or, Not,
    Amp,                     // &
    Dot, DotDot,
    Colon, Semi, Comma,
    LParen, RParen, LBrace, RBrace, LBracket, RBracket,
    Arrow,                   // =>
    Question, QuestionDot,   // ?, ?.
    QuestionQuestion,        // ??
    Bang,                    // !
    As,                      // as
    // 特殊
    Ident(String),
    Comment(String),         // 注释（直接丢弃，不传给 parser）
    DocComment(String),      // /// 文档注释
    Eof,
}
```

#### 3.2.2 关键字识别策略

使用 `phf` 或 `HashMap<&str, TokenKind>` 映射标识符到关键字。优先级：关键字 > 类型名 > 标识符。

```rust
fn lex_ident(lexer: &mut Lexer, start: &str) -> TokenKind {
    match start {
        // 关键字（40 个）
        "let" => TokenKind::Let,
        "mut" => TokenKind::Mut,
        // ...
        // 类型名
        "number" => TokenKind::NumberType,
        "string" => TokenKind::StringType,
        // ...
        // 字面量值
        "true" => TokenKind::True,
        "false" => TokenKind::False,
        // ...
        _ => TokenKind::Ident(start.to_string()),
    }
}
```

#### 3.2.3 字面量解析

| 格式 | 正则/规则 | Token |
|------|----------|-------|
| 整数 | `[0-9]+`（无 `.` 无 `n` 后缀） | `IntLiteral(i32)` |
| 浮点 | `[0-9]+ "." [0-9]+` | `FloatLiteral(f64)` |
| BigInt | `[0-9]+ "n"` | `BigIntLiteral(i64)` |
| 字符串 | `"..."` — 双引号，支持 `\"`、`\\`、`\n` 转义 | `StrLiteral(String)` |
| 模板字符串 | `` `...${expr}...` `` — 反引号，插值由 parser 处理 | `TemplateLiteral(Vec<TemplatePart>)` |

```rust
pub enum TemplatePart {
    Literal(String),
    Expr(Box<Expr>),  // parser 在 lexer 驱动下递归解析插值
}
```

#### 3.2.4 注释处理

- `// ...` → 遇到换行符停止 → 生成 `TokenKind::Comment`（不上传给 parser）
- `/* ... */` → 遇到 `*/` 停止，不可嵌套
- `/// ...` → 仅允许在 `export` 声明上方 → `TokenKind::DocComment`

#### 3.2.5 运算符优先级表

按 spec §LEX-REQ-003 的 15 级优先级表实现。Parser 采用 **Pratt parser（运算符优先级解析器）**模式：

```rust
fn precedence(tok: &TokenKind) -> u8 {
    match tok {
        TokenKind::LParen | TokenKind::Dot => 15,
        TokenKind::Bang | TokenKind::Question => 14,
        TokenKind::Amp => 13,
        TokenKind::As => 12,
        TokenKind::Star | TokenKind::Slash | TokenKind::Percent => 11,
        TokenKind::Plus | TokenKind::Minus => 10,
        TokenKind::QuestionDot => 9,
        TokenKind::QuestionQuestion => 8,
        TokenKind::EqEq | TokenKind::Ne | TokenKind::Lt | TokenKind::Gt
            | TokenKind::Le | TokenKind::Ge => 7,
        TokenKind::And => 6,
        TokenKind::Or => 5,
        TokenKind::Eq | TokenKind::PlusEq | TokenKind::MinusEq
            | TokenKind::StarEq | TokenKind::SlashEq | TokenKind::PercentEq => 4,
        _ => 0,
    }
}
```

### 3.3 Parser（语法分析器）（`parser.rs`）

#### 3.3.1 解析器架构

**递归下降 + Pratt parser（表达式层）**：

```
parse_program()
  → parse_imports()
  → parse_stmt() × N
       → parse_var_decl()      // let / let mut / const / shared
       → parse_function()      // function
       → parse_if()            // if / else
       → parse_for()           // for / for-of
       → parse_while()         // while
       → parse_loop()          // loop
       → parse_return()        // return
       → parse_break()         // break
       → parse_continue()      // continue
       → parse_expr_stmt()     // expression → parse_expr()
            → pratt_parse(0)   // Pratt parser for operators
```

#### 3.3.3 EBNF 产生式（Phase 1 子集）

```ebnf
-- SYN-REQ-001: 变量声明
var_decl ::= ("let" | "let" "mut") ident (":" type)? "=" expr ";?"
           | "const" ident (":" type)? "=" expr ";?"
           | "shared" ident (":" type)? "=" expr ";?"

-- SYN-REQ-002: 函数声明
function_decl ::= "function" ident "(" param_list? ")" (":" type)? ("{" stmt* "}" | "=" expr ";")
param         ::= ("inout" | "move")? ident (":" type)?
param_list    ::= param ("," param)*

-- SYN-REQ-003: 控制流
if_expr    ::= "if" "(" expr ")" block ("else" ("if" "(" expr ")" block | block))?
for_stmt   ::= "for" "(" ("let" ident "=" expr ";" expr ";" expr) ")" block
             | "for" "(" "let" ident "of" expr ")" block
while_stmt ::= "while" "(" expr ")" block
loop_expr  ::= "loop" block
return_stmt ::= "return" expr? ";?"
break_stmt ::= "break" expr? ";?"

-- SYN-REQ-006: 模块
import_decl ::= "import" (import_named | import_default | import_namespace) "from" string ";?"
export_decl ::= "export" ("default")? (function_decl | var_decl | type_decl | interface_decl)

-- SYN-REQ-009: 箭头函数与闭包
arrow_fn ::= ("move")? "(" param_list? ")" "=>" expr
closure   ::= ("move")? "(" param_list? ")" "=>" block

-- 表达式 (Pratt parser，优先级表 §LEX-REQ-003)
expr ::= primary
       | expr op expr        -- 二元运算（按优先级）
       | "&" expr            -- 引用
       | expr "!"            -- 断言解包
       | expr "?"            -- Result 传播
       | expr "as" type      -- 类型转换
       | expr "??" expr      -- 空值合并
       | expr "?." ident     -- 可选链
```

#### 3.3.4 调用处所有权标注

函数调用必须支持所有权标注：

```ts
function pushOne(inout arr: number[]) { ... }
pushOne(inout data);    // ✅
pushOne(data);          // ❌ parser 报错：缺少 inout（OWN-REQ-002）
```

调用处的标注语法：

```ebnf
call_arg ::= ("inout" | "move")? expr
call_expr ::= expr "(" call_arg ("," call_arg)* ")"
```

#### 3.3.5 错误恢复

**Panic mode 策略：**

当 parser 遇到语法错误时：
1. 生成一个 `Diagnostic`（error 级别）
2. 跳过后续 token 直到遇到同步点
3. 从同步点恢复解析（不终止编译）

**同步点列表：** `;`（可选语句分隔符）、`}`（块结束）、`function`、`import`、`export`、`type`、`interface`、`impl`、`test`、`async`

**验收标准：** 包含语法错误的 `.trust` 文件产生 ≥2 个诊断信息（AC-SYN-037），错误恢复后后续合法代码产出正确的 AST 节点（AC-SYN-038）。

### 3.4 模块图（`module_graph.rs`）

#### 3.4.1 功能

- 接收文件列表（入口 `.trust` 文件 + `import` 链）
- 构建 DAG（有向无环图）——检测循环导入
- 拓扑排序：被导入的文件先于导入文件解析

```rust
pub struct ModuleGraph {
    pub modules: HashMap<String, ModuleInfo>,  // path → info
    pub order: Vec<String>,                     // 拓扑排序结果
}

pub struct ModuleInfo {
    pub path: String,
    pub imports: Vec<String>,                   // 导入的文件路径列表
    pub exports: HashSet<String>,               // 导出符号列表
}
```

#### 3.4.2 循环导入检测

BFS/DFS 遍历依赖图，发现回边 → 生成错误 `"circular import detected: a.trust → b.trust → a.trust"`，列出完整循环路径。

#### 3.4.3 验收标准

- AC-MOD-001: `a.trust` import `b.trust`，`b.trust` import `a.trust` → 报循环导入错误
- AC-MOD-002: 三个文件无循环 → `order` 包含拓扑排序（深度优先后序）

### 3.5 导入解析（`resolve_imports.rs`）

#### 3.5.1 功能

三种导入格式：

```ts
import { foo, bar } from "./util";    // 命名导入
import greet from "./greet";          // 默认导入
import * as math from "./math";       // 命名空间导入
```

路径解析规则：
- `"./..."` → 相对当前文件目录
- `"/..."` → 相对项目根目录（`Trust.toml` 所在目录）
- `"std::..."` → 标准库路径（Phase 2+）

#### 3.5.2 验收标准

- AC-IMP-001: `import { add } from "./math";` → 解析路径 `./math.trust`
- AC-IMP-002: 未找到目标文件 → 报 `"module not found: ./math.trust"`
- AC-IMP-003: 导出不存在 → 报 `"symbol 'add' not exported from ./math.trust"`
