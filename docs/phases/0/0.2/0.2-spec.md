## 1. 成功标准

**MS-0.2-1（核心交付）：** `stdlib.md` 完成，覆盖 12 个模块（std::collections / sync / async / result / string / fs / rc / time / process / net / serde / crypto）。每个模块包含每个函数的完整签名（参数类型、返回类型、泛型约束）、一句话语义描述、对应 Rust 实现映射。

**MS-0.2-3（依赖图清晰）：** 模块间依赖图完整——明确哪些模块可以使用哪些模块，模块间的依赖不得引入循环引用。

> **说明：** "不透明类型"（如 `Sender<T>`/`Mutex<T>`/`TcpStream` 等）由运行时（ferro_rt）提供实现，stdlib 只需一行 `type Xxx<T>` 声明其存在 + API 表中列出方法签名，计为满足"最少类型定义数"。

### 3.2 内容格式约定

`stdlib.md` 每个模块按以下结构组织：

1. **模块概述**（1-3 句，说明模块职责）
2. **API 签名表**（函数名、签名、语义描述、Rust 映射）
3. **类型定义**（如 `Option<T>` 的两个变体、`Result<T,E>` 的 `Ok`/`Err` 变体）
4. **设计决策**（记录关键 API 设计选择与否决方案）
5. **验收标准**（checklist，每条可编写测试验证）

API 签名格式示例：

```ts
// std::fs — 文件系统操作

/// 读取文件全部内容到字符串
function readToString(path: string): Result<string, FsError>

/// 将字符串写入文件（覆盖）
function writeString(path: string, content: string): Result<void, FsError>
```

### 3.5 命名规范

Trust 标准库统一以下约定：

- **模块路径**：`std::module_name`（小写，snake_case）—— `std::collections`、`std::sync`
- **类型/接口**：`PascalCase` —— `Vec` `HashMap` `Option` `Result` `FsError` `HttpResponse`
- **函数/方法**：`camelCase` —— `readToString` `isSome` `toUpperCase` `fetchAdd`
- **常量**：`SCREAMING_SNAKE_CASE` —— `MAX_SIZE` `DEFAULT_TIMEOUT_MS`
- **关联函数/构造器**：`TypeName::functionName` —— `Box::new` `Vec::new` `Rc::new`
- **ADT 变体**：`PascalCase` —— `Some` `None` `Ok` `Err`

## 6. 模块依赖图

```
                    ┌─────────┐
                    │ result  │  (Option / Result — 所有其他模块的基础)
                    └────┬────┘
                         │
         ┌───────────────┼───────────────┐
         │               │               │
    ┌────▼────┐    ┌─────▼──────┐   ┌───▼────┐
    │ string  │    │ collections│   │  fs    │
    └─────────┘    └──┬─────┬───┘   └────────┘
                      │     │
                 ┌────▼──┐  │
                 │  rc   │◄─┘  (rc 可使用 collections)
                 └───┬───┘
                     │
                ┌────▼────┐
                │  sync   │  (Channel / shared / spawn — 依赖 rc 的 Arc + collections 的 VecDeque)
                └────┬────┘
                     │
                ┌────▼────┐
                │  async  │  (join / sleep — 依赖 sync 的 spawn)
                └────┬────┘
                     │
    ┌────────────────┼────────────────┐
    │                │                │
┌───▼───┐    ┌──────▼──────┐   ┌─────▼─────┐
│  net  │    │   process   │   │   time    │
└───────┘    └─────────────┘   └───────────┘
    │
┌───▼────┐
│ crypto │
└────────┘

serde —— 独立模块，不依赖其他 Trust std 模块（依赖 Rust serde 生态）
```

**规则：**
- `result` 是零依赖基础模块
- `collections`、`string`、`fs` 各自独立，仅依赖 `result`
- `rc` 依赖 `collections`（`Rc<Vec<T>>` 等场景）
- `sync` 依赖 `rc`（`shared` 使用 `Arc`，`Channel` 内部使用 `VecDeque`）+ `collections`
- `async` 依赖 `sync`（`spawn async` 使用 Tokio）
- `net` `process` `crypto` 依赖 `async` 或独立
- `time` 独立模块（无 Trust std 依赖）
- `serde` 独立模块（依赖 Rust serde 生态，无 Trust std 模块依赖）
- 禁止循环引用
