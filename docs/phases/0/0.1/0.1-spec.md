## 0. 文件说明

本规格书定义 **Phase 0.1**（编写 Trust Language Specification）的工程范围、成功标准、里程碑和验收条件。它描述"要写什么、怎么验收"——**不预写 Trust 语言规范本身的技术内容**。

Trust 语言规范的技术内容（关键词列表、优先级表、EBNF、类型规则等）在产出物 `spec/p0/0.1/trust-spec.md` 中，按照本规格书的要求逐域编写。

**一句话成功：** 任何实现者仅凭 `trust-spec.md` 即可无歧义地实现 Trust 编译器的 lexer、parser、type checker、borrow checker、codegen，无需查阅设计文档。

### 3.2 内容格式约定

`trust-spec.md` 每个域按以下结构组织：

1. **需求 ID + 描述**（如 `LEX-FR-001：关键字`）——定义语言特性
2. **设计决策**——记录为什么选择此方案、否决的替代方案
3. **验收标准**——checklist，每条具体到可编写测试

每个需求 ID 至少包含 2 条验收标准。验收标准格式为具体场景：`"输入 → 期望输出或行为"`。

### 3.3 各域的编写任务
